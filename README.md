## Open Web Framework

I chose to do nodejs for this lab.

To run this lab go into the node folder,
and run `node simple_rest.js`.
Depending on your installation it could be located at `nodejs` instead.

To use this project you can go to `http://localhost:8080/`
and `http://localhost:8080/index.html` to see a hello world.
You can go to `http://localhost:8080/path` to see a seprate path.
Any other page visted will return a 404.
